Thesis

What “that looks like fun” means here

A watcher thinks a tool looks fun when they can see cause and effect. The author does one thing and the screen answers at once: a box appears, a character steps onto the stage, the game jumps to the new line. Bret Victor calls this an immediate connection between the maker and the thing made (Inventing on Principle).

Studio already does most of the hard work. It checks as you type, reloads the running game on save, lights up the story map when scripts change, and draws a scene's opening shot. Almost none of that is visible to someone watching. The game plays in a floating window on top of Studio. Play is in a menu. Map boxes show names and file paths. Events rows are grey text. So the main job of this proposal is to put pictures and motion where the work already happens.

Three rules shaped every idea below:

Rule 1

Answer within a quarter second

Every action gets a visible answer on the same screen, fast. If the real result takes longer (a game launch, a check), show a sketch first.

Rule 2

Pictures first, text second, code last

A VN is pictures and words. Show the stage before the script and the script before the code.

Rule 3

Juice is a reward

Motion and sound mark real progress or show what changed. They are short, rare, and off with Reduce motion.

Group 1First five minutes

Time to first fun decides whether people stay. Unity's first-time tips say the first thing players touch should be the most engaging part, not setup (Unity); Roblox notes new players decide within minutes (Roblox). For Studio the “most engaging part” is a VN playing.

1.1

Double-click Studio

NewL
You see
  1. Download vn-engine-studio.zip from itch.io or GitHub.
  2. Unzip, double-click vn-engine Studio.
  3. The Start page opens (1.2). No Python, pip or terminal.
Why it's fun
Not watchable itself, but it decides whether there is anything to watch. Every step before the first window is a place to quit.
Borrowed from
Construct 3 runs in the browser with nothing to install (Construct guide). Today our README asks for Python, pip and a command.
Fits Studio
F42 already freezes games with PyInstaller (launcher_main, pinned and hashed deps). Studio starts children with python -m engine check/helper/run/build; a frozen Studio needs those as subcommands of its own exe. Tk is part of CPython on Windows and freezes well.
Needs, risks
Unsigned PyInstaller exes trip antivirus; signing costs money. Windows first. Keep the pip path for developers. The build tool (F42) inside a frozen Studio needs its own Python, which is the hardest part.
Build plan: 3 slices · ~760–1110k context · ≈7.5–11.0M counted · ≈0.70–1.02% of weekly

Challenged

Ideas I'd skip, for now

Multiplayer cursors

Figma's live cursors and Spotlight are lovely to watch (Figma help), and Roblox Studio has real-time collaborative scripting (Roblox docs). Studio is a solo tool on local files, and git already covers teams. Huge cost, little gain.

Embedding the game inside a Tk frame

It's the dream picture, and Godot does it (Godot docs). For us it means reparenting another process's SDL window into Tk: Windows-only, fragile with focus and DPI. Docking (2.3) gets 90 percent of the look.

A web build

pygbag runs pygame-ce in the browser and makes an itch.io zip, but needs an asyncio main loop with await asyncio.sleep(0) (pygbag). The engine has decode threads and a fixed loop. A big engine project; revisit after 7.1.

Block-based scripting

Scratch's blocks are perfect for logic (CACM). A VN is mostly words; blocks slow writing. The Events list with forms already gives non-programmers a no-code path.

Editing inside the running game

Godot's remote edits are lost when the game stops (Godot docs). Our script is the truth, and edit in Studio plus hot reload already persists.

A timeline editor

F45 and F47 left it out. VNs move line by line, and the stage preview's row scrubbing (2.5) covers what a timeline would show.

Celebrate everything, sound always on

Asana keeps its creatures occasional on purpose (Zapier). Juice on every keystroke turns into noise within an hour.

“Generate my whole game” on New game

The Assistant (F48) already helps. Writing the story is the fun part; a generated game takes it away and leaves a stranger's draft to fix.
